Features

One-click launch

Double-click and AC Studio opens, fully configured. No setup, no dialogs.

Non-destructive

Works on a temporary copy. Your original AC Studio.exe is never modified.

Auto-cleanup

The working copy is deleted automatically when you close AC Studio.

Splash screen

Minimal dark UI shows patch progress before the editor opens.

Version detection

Reads the AC Studio version and displays it in the window title.

Tiny footprint

~200 KB. No installer, no admin rights, no background processes.

Frequently Asked Questions

Does SMK Launcher modify my AC Studio.exe?

No. It only reads the original file to make a temporary copy. The original is never written to.

What is the difference between AC Studio and KS Editor?

KS Editor is the original official editor from Kunos Simulazioni, now outdated. AC Studio is a community-built alternative with a modern interface and more features.

Does it work with KN5 files?

Yes. AC Studio fully supports the KN5 format used by Assetto Corsa for cars and tracks.

Do I need to reinstall the launcher after AC Studio updates?

Usually no. The launcher adapts automatically. If a major update changes the editor's internals, a launcher update may be released.

Is there an AC Studio free version?

Yes — the Free edition is available via the download link above. SMK Launcher is designed to work with this version.

Does this work on Windows 10?

Yes. Windows 10 64-bit and Windows 11 are both fully supported.
